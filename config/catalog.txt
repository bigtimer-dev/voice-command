# Commands the assistant may choose when no phrase matched exactly.
# "canonical phrase | what it is for". N = a number. Dangerous commands
# (shutdown, restart, close window) are left out on purpose: they need the exact phrase.
open agent | Claude Code AI coding assistant; programming, writing code, asking the AI agent
open browser | web browser; browsing, searching the web, reading a website
open terminal | command line shell
open files | file manager; finding documents, downloads, folders
open spotify | music app; wanting to listen to music (when nothing is playing)
open youtube | videos; wanting to watch something or a video
open settings | system settings: wifi, bluetooth, sound, display
fullscreen window | make the current window fill the screen, or leave fullscreen
lock screen | lock the computer when leaving
play pause music | pause, resume, stop or continue whatever is playing
next song | skip to the next track
previous song | go back to the previous track
volume up | louder; can't hear well
volume down | quieter; too loud
set volume to N | set the volume to a percentage
mute | silence or unmute all sound
go to workspace N | switch to desktop/workspace number N
move window to workspace N | send the current window to workspace N
search youtube for X | find videos about something on YouTube (X = what to search)
search the web for X | look something up on Google: news, prices, weather, how-to (X = search text)
remind me in N minutes to X | reminder after N minutes (convert hours to minutes) with message X
set a timer for N minutes | countdown timer of N minutes
play on spotify X | play an artist, song or playlist on Spotify (X = what to play)
